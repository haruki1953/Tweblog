你要求的结构：

## 3. forward.ts（PocketChat 转发主流程）

这是整个平台的核心。

### 主流程：

1. 获取 session（token + authorId）
2. 处理所有图片 → 上传 → 得到 imageRecordIds
3. 文本拆分 → textChunks
4. 图片分组 → imageGroups
5. **发送文字消息（如果 textChunks.length > 0）**
    - 第一条：replyMessage = undefined
    - 后续：replyMessage = 上一条文字消息 id
    - 最后一条文字消息 id = rootMessageId
6. **发送图片消息**
    - 如果 textChunks.length === 0：
        - rootMessageId = undefined
    - 每组图片：
        - replyMessage = rootMessageId
7. 返回：
    - resPostInfo
        - platformPostId = rootMessageId 或最后一条消息 id
        - platformPostLink = `${host}/?id=${id}&created=${created}`
    - resImageList

### 绝对不发送空内容消息

你特别强调了：

> textChunks.length === 0 时，不要发空内容消息  
> 直接只发图片消息
